# Security

LinuxRunner executes Linux programs within a single iOS application. The iOS sandbox is the outer security boundary. Linux users, permissions and guest processes do not confine hostile code from the host app or one another. Shared folders and network access expose the resources granted to the app.

Use [GitHub private vulnerability reporting](https://github.com/mxhm11cr/LinuxRunner/security/advisories/new) for sensitive reports. If that channel is unavailable, do not put exploit details or private data in a public issue. Ordinary crashes and application compatibility problems can be reported through the repository's issue tracker.

Include the app version and build, device model, iOS version and a minimal reproduction. Review logs for credentials and personal data before sharing them. Upstream projects have their own reporting policies.
