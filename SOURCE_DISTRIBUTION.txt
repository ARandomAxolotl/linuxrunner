LinuxRunner 1.0.1 source distribution

Release: https://github.com/mxhm11cr/LinuxRunner/releases/tag/v1.0.1

LinuxRunner-1.0.1-source.tar.gz contains the application and build scripts,
four exact dependency snapshots, the bundled Alpine packages' matching recipes
and checksum-verified source inputs, and matching Ghostty Web/Ghostty sources.
SOURCE_CONTENTS.txt and SOURCE_MANIFEST.json describe the archive.

Minimal shallow Git snapshots allow build scripts to resolve revisions without
private development history or credentials. The unused deps/linux pin is retained
but its checkout is not needed by the application release scheme.

LICENSES.txt combines the application declarations and third-party notices.
SHA256SUMS covers the IPA, corresponding-source archive and license notices.
GitHub automatic source archives omit submodule contents; use the attached source
asset for the complete packaged source distribution.

The IPA has an ad-hoc signature but no Apple provisioning profile. It requires a
compatible signing/provisioning method for ordinary physical-device installation.
No certificate, private key or provisioning profile is part of the source archive.
