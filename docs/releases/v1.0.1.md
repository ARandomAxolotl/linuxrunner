# LinuxRunner v1.0.1

Linux on your iPhone and iPad. This update adds iPad desktop adaptations, brings Arch Linux ARM into the setup workflow and improves package recovery and desktop sessions.

## What's New

- **iPad support:** window-aware desktop sizing, hardware-keyboard desktop shortcuts and the shared touch/pointer interface. Tested on a physical iPad.
- **Arch Linux ARM:** install signed packages, use `pacman` and explore an experimental Openbox desktop with LXQt Panel and PCManFM-Qt.
- **One setup workflow:** **Distributions → Set Up Linux…** installs a distribution or configures an existing environment while preserving its files and accounts.

The maintainer reports a working Arch graphical desktop and graphical application launches on a physical iPhone using **build 897**. Telegram Desktop has been tested on Arch Linux ARM with login, sending messages and calls. The supplied iPhone capture shows its welcome screen.

## Improvements

Arch desktop defaults provide a visible panel, wallpaper and file manager without replacing the user's normal LXQt configuration. Managed graphical launches share the active account's authenticated X11 context. Desktop startup status and Qt diagnostics are more useful when a component fails.

IPA packaging now includes an ad-hoc code signature and a standard ZIP layout. It still needs a compatible signing/provisioning method for ordinary device installation.

## Bug Fixes

- Arch terminal termios2 compatibility.
- Signed cached-package recovery and consistent handling of orphaned GCC ownership/obsolete recovery state.
- Qt X11 launch-context failures and desktop profile defaults.
- Reopening existing desktop sessions and readiness after component crashes.
- ARM64 vDSO executable mapping and covered filesystem/syscall compatibility gaps.

## Supported Distributions

| Distribution | Experience |
| --- | --- |
| Debian GNU/Linux 13 ARM64 | Recommended terminal and LinuxRunner Desktop; KDE Plasma remains experimental. |
| Arch Linux ARM | Terminal, `pacman` and experimental Openbox/LXQt-component desktop. |
| Alpine Linux 3.24 ARM64 | Small terminal environment with `apk`; graphical compatibility remains experimental. |

## Installation

Download the release IPA and sign/install it with your preferred compatible sideloading tool, such as Sideloadly or AltStore Classic. Then use **Distributions → Set Up Linux…** to install Linux inside the app.

See the [installation guide](https://github.com/mxhm11cr/LinuxRunner#installation) and [Linux setup walkthrough](https://github.com/mxhm11cr/LinuxRunner/blob/v1.0.1/docs/GETTING_STARTED.md). When updating, back up important files and preserve the existing app identity and App Group configuration. Do not uninstall the app as a repair step.

## Known Limitations

The application interprets ARM64 Linux userspace; it does not boot a Linux kernel, require JIT or use hardware virtualization. System-call and application coverage is incomplete. The configured minimum is iOS/iPadOS 15.0; model/OS compatibility is not universal. iPad support has been physically tested. An older iPhone 11/iOS 17 launch-black-screen report is unresolved.

Arch desktop, Debian KDE Plasma and Metal acceleration remain experimental. Arch Plasma/Wayland is unavailable. Some Arch GTK/glycin programs still encounter write-seal compatibility problems. Large applications can be slow or exceed memory limits. iOS/iPadOS may suspend or terminate the app; saved files persist, running processes do not survive termination.
